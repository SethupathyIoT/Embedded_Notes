# Embedded C

## Scope

This section develops C for embedded systems, from language fundamentals to hardware-oriented firmware design.

## Book source

Primary source: *Programming Embedded Systems: A 10-week course, using C* by Michael J. Pont, version v1.4a.

## Learning sequence

1. [Basics](01_Basics/README.md)
2. Data types
3. Operators
4. Control flow
5. Functions
6. Pointers
7. Arrays and strings
8. Structures and unions
9. Preprocessor
10. Memory
11. Embedded C practices

## Book-derived seminar map

- Seminar 1: Hello, Embedded World
- Seminar 2: Basic hardware foundations: resets, oscillators, and port I/O
- Seminar 3: Reading switches
- Seminar 4: Adding structure to your code
- Seminar 5: Meeting real-time constraints
- Seminar 6: Creating an embedded operating system

These headings are transcribed as a high-level map from the source table of contents. Detailed notes will be added incrementally.
