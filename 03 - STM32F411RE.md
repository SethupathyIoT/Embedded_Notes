- STM32F411RE
  - Device summary
    - Source: STM32F411xC/xE family uses an Arm Cortex-M4 core.
    - Source: Up to 100 MHz operating frequency.
    - Source: Up to 512 KB Flash and 128 KB SRAM.
    - Source: 12-bit ADC, DMA controllers, timers, USART/UART, SPI/I2S, and I2C interfaces.
    - Source: Supply range is 1.7 V to 3.6 V for the MCU and I/O domain.
  - Memory map concepts
    - Flash
      - Source: Program memory is mapped in the 0x0800 0000 region for STM32 devices in this family.
    - SRAM
      - Source: SRAM is mapped in the 0x2000 0000 region.
    - Peripheral region
      - Source: Peripheral registers are mapped in the 0x4000 0000 region.
    - AHB/APB buses
      - AHB commonly hosts GPIO, DMA, and memory-interface peripherals.
      - APB buses commonly host timers and communication peripherals.
  - Clock and reset
    - RCC controls clock distribution and reset of peripherals.
    - Peripheral clock must be enabled before accessing most peripheral registers.
    - Exact bus clock and timer-clock behavior must be calculated from the configured clock tree.
  - GPIO checklist
    - Enable GPIO port clock.
    - Configure mode.
    - Configure output type.
    - Configure speed.
    - Configure pull-up/pull-down.
    - Select alternate function when using a peripheral.
  - Peripheral checklist
    - Enable peripheral clock.
    - Configure GPIO alternate function.
    - Configure peripheral timing and mode.
    - Clear pending flags where required.
    - Enable peripheral and/or interrupt.
    - Test with a logic analyzer or debugger.
