# Embedded Notes

A structured, Logseq-style knowledge base for embedded systems, firmware, ARM Cortex-M, STM32, communication protocols, RTOS, and hardware/software design.

## Note format

- Every topic is written as nested bullets for easy import into Logseq.
- Source-derived points are marked with `Source:`.
- Practical explanations and recommendations are marked with `Practical:`.
- MCU-specific register details must be checked against the exact STM32 reference manual/datasheet.
